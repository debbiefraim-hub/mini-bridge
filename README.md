# מיני ברידג׳ — 4 שחקנים

שרת Node.js למשחק קלפים בעברית עם ארבעה שחקנים אמיתיים בחדר פרטי.

## הפעלה

1. התקינו Node.js 18 ומעלה.
2. פתחו מסוף בתיקיית המשחק.
3. הריצו `npm install`.
4. הריצו `npm start`.
5. פתחו בדפדפן `http://localhost:3000`.

למשחק בין ארבעה מכשירים דרך האינטרנט, יש לפרוס את התיקייה בשירות אירוח Node.js שתומך ב-WebSockets, ולהשתמש בכתובת HTTPS של השירות. פתיחת localhost בלבד אינה מאפשרת לשחקנים מרוחקים להתחבר.

## חוקים
- 13 סיבובים, 1–13 קלפים לכל שחקן.
- בסיבובים 1–12 השליט נקבע מקלף אקראי שלא חולק; בסיבוב 13 אין שליט.
- מסיבוב 5 המכריז האחרון אינו רשאי לגרום לסכום ההכרזות להיות שווה למספר הקלפים בסיבוב.
- חובה ללכת בעקבות הסדרה הפותחת, אם אפשר.
- ניקוד מדויק: 10 + ריבוע ההכרזה; אחרת מספר הלקיחות בפועל.
- סדר המושבים מוגרל עם תחילת המשחק; הפותח מתחלף בכל סיבוב.

## מגבלות גרסה ראשונה
- חדרים נשמרים בזיכרון השרת בלבד; אתחול השרת מוחק משחקים.
- שחקן שהתנתק יכול להיכנס מחדש עם אותו שם וקוד חדר כל עוד השרת פועל.
- אין חשבונות, שמירת היסטוריה קבועה או סיסמת חדר.
- מנהל החדר הוא יוצר החדר לפני ההגרלה; לאחר ההגרלה כפתורי ניהול זמינים למושב 0.
